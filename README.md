# AI Cross-Validator | AI 输出交叉验证工具

AI 的错误率还是很高。这个工具通过**多 session 独立调用 + 自动融合分析**，帮你快速识别 AI 回答中哪些可信、哪些存疑。

## 原理

同一个问题，同时发送给多个完全独立的 session（无共享上下文），再将所有回答交给另一个 session 进行融合分析：

- 🟢 **多个 session 一致的观点** → 大概率可信
- 🔴 **各 session 之间存在分歧的观点** → AI 可能在瞎编
- 🟡 **仅个别 session 提到的观点** → 需要额外验证

这个方法对标企业级决策验证框架中的 **Delphi 法**（德尔菲法）——多位独立专家匿名回答同一问题，汇总比对后迭代收敛出共识。

## 使用方式

这是一个 React Artifact，直接在 Claude App（手机/电脑）中运行：

1. 在 Claude 对话中，让 Claude 创建一个 React artifact，把 `cross-validate.jsx` 的代码给它
2. Artifact 会在对话界面中打开
3. 输入你要验证的问题
4. 选择调用次数（2 / 3 / 5）
5. 点击「发送验证」
6. 等待融合分析结果

## 功能

- **并行独立调用**：每次调用都是全新 session，互不影响
- **自动融合分析**：所有回答返回后，自动发送给一个新 session 进行比对
- **三色标记**：一致（🟢）、分歧（🔴）、仅个别提及（🟡）
- **原始回答可查**：融合结果下方可展开查看每条原始回答

## 背后的方法论

这个工具是 **AI 输出验证方法论** 中「路径二：笼统/开放性问题」的自动化实现。完整方法论包含三条独立验证路径：

| 路径 | 适用场景 | 核心方法 | 企业对标 |
|------|---------|---------|---------|
| 路径一 | 大问题 / 复杂问题 | 逐层分解 + 每层验证 | Red Team, Pre-Mortem, MECE |
| **路径二** | **笼统 / 开放性问题** | **多 session 交叉验证（本工具）** | **Delphi 法** |
| 路径三 | 需要硬结论的问题 | 确定性验证（论文/权威来源） | 尽职调查, 同行评审 |

## 技术细节

- 运行环境：Claude App 内的 Artifact（React）
- API：Anthropic Messages API（`/v1/messages`）
- 模型：Claude Sonnet（成本较低，适合多次调用）
- 无需后端，无需额外部署
